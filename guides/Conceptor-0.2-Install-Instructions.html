Version 0.2 · 19 November 2026

Read this first

Conceptor 0.2, 19 November 2026. This guide covers each device separately. Do the steps in order, one at a time.

Android 1: What you need

  • An Android phone with Android 8.0 or later.
  • A 64-bit phone. Nearly all phones from 2017 onward are.
  • About 40 MB of free space, plus space for songs.
  • The file Conceptor-0.2.apk. Get it from the GitHub release page (next step) or from the Builds chat.
  • Headphones for recording.

Already have Conceptor 0.1? Read Android 7 first. Version 0.1 must be removed before 0.2 goes on.

Android 2: Download the app file

Way A: on the phone.

  1. Open Chrome on the phone.
  2. Go to github.com/ftumch78/Conceptor-Android-0.1/releases/latest
  3. Sign in to GitHub if asked. The Conceptor repository is private, so the account needs access to it.
  4. Under Assets, tap Conceptor-0.2.apk.
  5. If Chrome asks whether to keep the file, tap Download anyway.

Way B: from a computer.

  1. Download Conceptor-0.2.apk from the Builds chat or the release page.
  2. Send it to the phone: by email to yourself, Google Drive, or a USB cable.
  3. On the phone, open the file from the email, Drive or the Files app.

Android 3: Open the file

  1. When the download finishes, tap Open at the bottom of the screen.
  2. If the message has gone: open the Files app, tap Downloads, tap Conceptor-0.2.apk.

Android 4: Allow the install

Android blocks apps that do not come from the Play Store until you allow it once.

  1. A message says the phone is not allowed to install unknown apps from this source. Tap Settings.
  2. Switch on Allow from this source.
  3. Press the back button once.

Android 5: Install

  1. The install box shows Conceptor. Tap Install.
  2. Wait a few seconds.
  3. Tap Open, or find the Conceptor icon in the app list.

If a Play Protect box appears:

  1. Tap More details.
  2. Tap Install anyway.

This box appears because the app is not from the Play Store. It does not mean anything is wrong with the file.

Android 6: First start

  1. Open Conceptor.
  2. Tap Start.
  3. Tap Allow the microphone, then While using the app.
  4. Type a name for the first song. Tap Create the song.
  5. The Mix screen opens. The app is ready.

Without the microphone, playback and mixing work but recording does not. To allow it later: phone Settings, Apps, Conceptor, Permissions, Microphone, Allow.

Android 7: Updating from version 0.1

Version 0.2 uses a new, fixed signing key. Version 0.1 had a temporary one. Android will not install 0.2 over 0.1, so 0.1 has to be removed once. From 0.2 onward, new versions install over the old one and songs are kept.

  1. Open Conceptor 0.1.
  2. For each song you want to keep: open it, then Menu, Export the mix (WAV). Save the file to Drive or Files.
  3. Hold the Conceptor icon. Tap App info. Tap Uninstall. Tap OK.
  4. Install 0.2 from Android 2.
  5. To bring an old song back in: open a track, tap Import audio and choose the saved WAV file.

Uninstalling removes the songs stored inside the app. Export first.

Android web app (no download)

  1. Open Chrome on the phone.
  2. Go to ftumch78.github.io/conceptor-web.
  3. Tap Open Conceptor.
  4. Tap the three dots at the top right of Chrome.
  5. Tap Add to Home screen or Install app, then Install.
  6. Start Conceptor from its new icon.

The Android app has better recording timing than the web app. Use the app for recording when possible.

iPhone and iPad 1: Open the page in Safari

  1. Open the Safari app.
  2. Go to ftumch78.github.io/conceptor-web.
  3. Tap Open Conceptor.

Needs iOS or iPadOS 15 or later. Use Safari for these steps.

iPhone and iPad 2: Tap Share

  1. Tap the Share button: the square with an arrow pointing up.
  2. iPhone: at the bottom of the screen. iPad: at the top right.

iPhone and iPad 3: Add to Home Screen

  1. Scroll down the list.
  2. Tap Add to Home Screen.

iPhone and iPad 4: Tap Add

  1. Leave the name as Conceptor.
  2. Tap Add at the top right.

iPhone and iPad 5: Open Conceptor

  1. Go to the home screen.
  2. Tap the Conceptor icon. It opens full screen, like an app.
  3. Tap Start, then Allow the microphone, then Allow.

iPhone and iPad 6: Sound settings

  • Switch off Silent mode (the switch or Action button on the side). In Silent mode web apps make no sound.
  • Wear wired headphones, or headphones plugged into an adapter, for recording. Bluetooth headphones add a delay.
  • Songs are kept on this iPhone or iPad only. Use Export to keep copies.

If the microphone was refused: Settings, Safari, Microphone, Ask or Allow. Then close Conceptor fully and open it again.

Mac and PC 1: Open Conceptor

  1. Open Chrome or Microsoft Edge (Safari also works on a Mac).
  2. Go to ftumch78.github.io/conceptor-web.
  3. Click Open Conceptor.

Mac and PC 2: Install it as an app

Chrome or Edge:

  1. Click the install icon at the right end of the address bar.
  2. Click Install.
  3. Conceptor opens in its own window. It is added to the Dock (Mac) or the Start menu (PC).

Safari on a Mac with macOS Sonoma or later: File, Add to Dock, Add.

Older Macs, for example macOS Catalina: use Conceptor in a Safari or Chrome window and bookmark it. Safari 15 or later is needed.

Mac and PC 3: Microphone and audio interface

  1. Click Start, then Allow the microphone. Click Allow in the browser box.
  2. To record from an audio interface: Menu, Input and output, choose it under Record from.
  3. Sound plays through the computer's normal output. Change it in the computer's sound settings.

Mac: if no box appears, open System Settings, Privacy and Security, Microphone, and switch on the browser.
