Not finished in this version:

  • Songs made on Android cannot be opened in the desktop apps, and the other way round. Each keeps its own songs. Use Bounce or Export to move the sound across.
  • The Windows and Mac apps are not signed, so Windows and macOS show a warning the first time. The steps below show what to press.

What is new in 0.4.4

  • Two versions: Conceptor - Light (fewer controls, made for phones) and Conceptor - Heavy (every control, desktop apps).
  • Every time the app opens, the start screens show one at a time: the version (desktop apps) or Light version only (phone), Audio hardware, Library settings, then Start.
  • Start has four choices: New Song, Open an existing song, Turn on the Ultrasound Machine, View Library.
  • The main screen: the menu is a palette of coloured hexagons in the top half. The faders are in the bottom half. Everything fits on the screen.
  • Light: up to 4 tracks. One track records at a time. Drum patterns are 2 bars.
  • Light: Wave on a track opens a pop-up with Insert Silence, Drop In spots (IN and OUT) and Gain. With spots set, Drop In starts at IN and stops at OUT by itself.
  • Light: Bounce makes the mix, then trim and fade out (Off, 2, 5 or 10 seconds), then Save.
  • Heavy: everything from 0.4.3, with smaller hexagons beside the All Waves overview.
  • Lt. Joe Bookman, My Songs, has a Heavy folder and a Light folder. Light opens Light songs only.

Start screens (every time it opens)

  1. Step 1: phone: press Proceed. Desktop app: choose Light or Heavy, then Next.
  2. Step 2, Audio hardware: phone: Phone Mic or USB mic. Desktop app: the input, the output, the input levels and the recording delay. Then Next.
  3. Step 3, Library settings: where songs are kept. Phone (or This computer), SD card (Android), External drive (computer) or Cloud drive. For SD card, external drive or cloud drive, press Choose folder. Then Next.
  4. Step 4, Start: New Song, Open an existing song, Turn on the Ultrasound Machine, or View Library.

Light: recording

  1. Press the red button on a track strip. It turns red. Pressing it on another track moves it there: one track at a time.
  2. Press the red Record button in the top bar. Play or sing. The counter turns red.
  3. Press Play (the square) to stop. Or |<< to stop and go back to 0:00.
  4. Add Track adds a track, up to 4.

Light: Wave pop-up and Drop In spots

  1. Press Wave on a track strip.
  2. Insert Silence: paint over the part to silence. Preview, then Apply.
  3. Drop In spots: tap the wave for IN, then again for OUT. Press Apply.
  4. Gain: turn the knob, then Apply.
  5. Press Done. Then Drop In (palette): pick the track and the run-up. Recording starts at IN and stops at OUT by itself.

Light: Bounce

  1. Press Bounce in the palette.
  2. Drag the gold lines to trim the start and the end. Play from cursor to listen.
  3. Fade out: Off, 2 s, 5 s or 10 s.
  4. Press Save. It goes to Lt. Joe Bookman, Mixes. Then Add to Playlist, Play in Ultrasound, View in Library, Share File or Close.

Heavy (Mac and Windows apps)

  • Everything from 0.4.3 is here: two tracks at once, Edit Mode, Trim, pedals, amp, 7-band EQ, Demo and Polished, Export with mastering.
  • The palette's Light or Heavy hexagon changes the version (back to the start screens).
  • Home in the palette goes back to the Start screen.

Android update

0.4.4 installs over the old version. Songs stay, in the Light folder. A song with more than 4 tracks shows the first 4; the others are kept.

  1. On the phone, open Chrome.
  2. Go to github.com/ftumch78/Conceptor-Android-0.1/releases/latest
  3. Sign in to GitHub if asked.
  4. Under Assets, tap Conceptor-0.4.4.apk.
  5. When the download finishes, tap Open.
  6. Tap Update (or Install).
  7. Open Conceptor - Light. It shows upright. Go through the start screens.

Android new install 1: Download

  1. On the phone, open Chrome.
  2. Go to github.com/ftumch78/Conceptor-Android-0.1/releases/latest
  3. Sign in to GitHub if asked. The repository is private, so the account needs access.
  4. Under Assets, tap Conceptor-0.4.4.apk.
  5. If Chrome asks whether to keep the file, tap Download anyway.

No GitHub access? Conceptor-0.4.4.apk is also in the Conceptor Downloads folder and the Builds chat. Send it to the phone by email or Google Drive, then tap it on the phone.

Android new install 2: Allow the install

  1. Tap Open when the download finishes, or find the file in Files, Downloads.
  2. If the phone says it is not allowed to install unknown apps, tap Settings.
  3. Switch on Allow from this source.
  4. Press the back button once.

Android new install 3: Install

  1. Tap Install.
  2. If a Play Protect box appears, tap More details, then Install anyway.
  3. Tap Open.

Android new install 4: First start

  1. Hold the phone upright.
  2. Tap Proceed.
  3. Tap Phone Mic (or USB mic), then While using the app for the microphone. Tap Next.
  4. Tap Phone (or SD card or Cloud drive). Tap Next.
  5. Tap New Song.
  6. The main screen opens. Press and hold any button to see its name (with Hand Hold on).

iPhone and iPad

Already on the home screen: open Conceptor while online. It updates itself. If it still has the old layout (a Master bar across the top), close it fully (swipe it away) and open it again. Hold it upright. Conceptor - Light shows in portrait on a phone.

New:

  1. Open Safari.
  2. Go to ftumch78.github.io/conceptor-web.
  3. Tap Open Conceptor.
  4. Tap Share (the square with an arrow).
  5. Tap Add to Home Screen, then Add.
  6. Open Conceptor from the home screen. Tap Proceed, then Phone Mic, and Allow for the microphone.

Switch off Silent mode, or there is no sound. Songs are kept on this iPhone or iPad. Use Export to keep copies.

Windows app

  1. On the computer, go to github.com/ftumch78/conceptor-web/releases/latest.
  2. Under Assets, click Conceptor-0.4.4-Windows-Setup.exe. It downloads.
  3. Open the downloaded file (click it at the bottom or top of the browser, or find it in Downloads).
  4. A blue box may say Windows protected your PC. Click More info.
  1. Click Run anyway.
  2. Conceptor installs and opens by itself. It has an icon on the desktop and in the Start menu.
  3. Allow the microphone if Windows asks.
  4. Choose Light or Heavy, then the audio interface, then the library, then New Song. One screen at a time.

Updating later: download the new Setup file and open it. It replaces the old version. Songs are kept.

Mac app

  1. On the Mac, go to github.com/ftumch78/conceptor-web/releases/latest.
  2. Under Assets, click Conceptor-0.4.4-Mac.dmg. It downloads.
  3. Open the downloaded file. A window opens.
  4. Drag Conceptor onto Applications.
  1. Open the Applications folder.
  2. The first time only: right-click (or Control-click) Conceptor, then click Open.
  1. A box says macOS cannot verify the developer. Click Open.
  2. From then on, open Conceptor normally (Dock, Launchpad or Applications).
  1. The first time you record, macOS asks about the microphone. Click OK.

Updating later: download the new .dmg, drag Conceptor onto Applications, and click Replace. Songs are kept.

Mac and PC in the browser

Already installed from Chrome or Edge: open it while online. It updates itself. If it still has the old layout, close the window and open it again.

New:

  1. Open Chrome or Edge (Safari also works on a Mac).
  2. Go to ftumch78.github.io/conceptor-web.
  3. Click Open Conceptor.
  4. Click the install icon at the right end of the address bar, then Install.
  5. Press Proceed, then go through the start screens one at a time.

Library in OneDrive or Google Drive (computer)

Needs Chrome or Edge on a computer, and the OneDrive or Google Drive app on that computer.

  1. Open Conceptor. On step 3, Library settings, choose Cloud drive, then the cloud app.
  2. Press Choose folder. Pick the OneDrive or Google Drive folder. Allow Conceptor to use it.
  3. Press Sync Library, then A synced folder, then Start sync (or Combine and sync if a Library is already there).

Conceptor makes a folder called "Conceptor Library". Each song is a folder inside it, with song.txt, the track WAV files and the exported mixes. Nothing is deleted when syncing. If the same song was changed in two places, both copies are kept.
