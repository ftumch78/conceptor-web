What is new in 0.4.2

  • Conceptor for Windows and Mac: an installer for Windows 10 and 11, and a Mac app for macOS 10.15 Catalina or later (Intel and Apple Silicon).
  • They are the same Conceptor as the web app, in their own window, and work without the internet.
  • The Library sync folder (OneDrive or Google Drive) works in both apps.
  • The Android app stays at 0.4.1. Nothing changed for Android in this update.

What was new in 0.4.1

  • New colours, the same as Birthing Unit: dark grey with a faint honeycomb, a black top bar with a gold line, and a green time display.
  • On and selected buttons are mint. Play is green. Record is red.
  • Drum programmer: the song row now sits directly under the pattern cards, so dragging a card into it is a short move. The pattern editor is underneath.
  • Patterns are 2 or 4 bars long. Number of bars: press 2 or 4 (the chosen one turns yellow).
  • The grid shows 2 bars at a time, so the squares are bigger. With 4 bars, the switch shows Bars 1 & 2 or Bars 3 & 4.
  • Everything from 0.4 is still there: Demo Mode and Polished Mode, Placeholder, the sound knobs, Import Audio, Edit Sound and Reset Sound.

Using the new drum programmer

  1. Open the Menu, then Drum programmer. Or press Drums at the bottom of the Mix screen.
  2. Pattern cards are at the top. Tap one to edit it. Press + New pattern for another.
  3. The editor is at the bottom. Press 2 or 4 for the number of bars. Tap squares to add hits. With 4 bars, use the switch to see bars 3 and 4.
  4. Tap a sound name on the left of the grid to choose which sound the knobs change.
  5. To put a pattern in the song: press Add to row. Or hold the card and drag it down into the row just under the cards.
  6. Tap a block in the row to select it, then Repeat or Remove. Hold a block to move it, or drag it out of the row to remove it.
  7. Press Play at the bottom. The playing block has a gold outline.

Placeholder: tick the box on a pattern. It fills the row up to the song length. Change the minutes and seconds under the tick box. Patterns dropped onto a striped block replace it.

Android update (from 0.3 or 0.4)

0.4.1 installs over 0.3 and 0.4. Songs stay. Old drum grids become Pattern 1 (4 bars). Songs from 0.3 that had mastering on open in Polished Mode.

  1. On the phone, open Chrome.
  2. Go to github.com/ftumch78/Conceptor-Android-0.1/releases/latest
  3. Sign in to GitHub if asked.
  4. Under Assets, tap Conceptor-0.4.1.apk.
  5. When the download finishes, tap Open.
  6. Tap Update (or Install).
  7. Open Conceptor. Your songs are in the Library.

Still on 0.1? Remove 0.1 first (hold the icon, App info, Uninstall), then install 0.4.1. Export any songs from 0.1 before removing it.

Android new install 1: Download

  1. On the phone, open Chrome.
  2. Go to github.com/ftumch78/Conceptor-Android-0.1/releases/latest
  3. Sign in to GitHub if asked. The repository is private, so the account needs access.
  4. Under Assets, tap Conceptor-0.4.1.apk.
  5. If Chrome asks whether to keep the file, tap Download anyway.

No GitHub access? The file Conceptor-0.4.1.apk is also in your Conceptor Downloads folder and in the Builds chat. Send it to the phone by email or Google Drive, then tap it on the phone.

Android new install 2: Allow the install

  1. Tap Open when the download finishes, or find the file in Files, Downloads.
  2. If the phone says it is not allowed to install unknown apps, tap Settings.
  3. Switch on Allow from this source.
  4. Press the back button once.

Android new install 3: Install

  1. Tap Install.
  2. If a Play Protect box appears, tap More details, then Install anyway.
  3. Tap Open.

Android new install 4: First start

  1. Tap Start.
  2. Tap Allow the microphone, then While using the app.
  3. Leave the name as "Untitled" and the date, or type one. Tap Create the song.
  4. Choose Demo Mode or Polished Mode. Tap Open song.
  5. The main screen opens. The (i) buttons explain each part. Tap one, read it, tap Got it.

iPhone and iPad

Already on the home screen: open Conceptor while online. It updates itself. If it still looks like 0.4 (yellow buttons, no honeycomb), close it fully (swipe it away) and open it again.

New:

  1. Open Safari.
  2. Go to ftumch78.github.io/conceptor-web.
  3. Tap Open Conceptor.
  4. Tap Share (the square with an arrow).
  5. Tap Add to Home Screen, then Add.
  6. Open Conceptor from the home screen. Tap Start, then Allow for the microphone.

Switch off Silent mode, or there is no sound. Songs are kept on this iPhone or iPad. Use Export to keep copies.

Windows app

  1. On the computer, go to github.com/ftumch78/conceptor-web/releases/latest.
  2. Under Assets, click Conceptor-0.4.2-Windows-Setup.exe. It downloads.
  3. Open the downloaded file (click it at the bottom or top of the browser, or find it in Downloads).
  4. A blue box may say Windows protected your PC. Click More info.
  1. Click Run anyway.
  2. Conceptor installs and opens by itself. It has an icon on the desktop and in the Start menu.
  3. Allow the microphone if Windows asks.
  4. Choose the audio interface in the Menu, Input and output.

Updating later: download the new Setup file and open it. It replaces the old version. Songs are kept.

Mac app

  1. On the Mac, go to github.com/ftumch78/conceptor-web/releases/latest.
  2. Under Assets, click Conceptor-0.4.2-Mac.dmg. It downloads.
  3. Open the downloaded file. A window opens.
  4. Drag Conceptor onto Applications.
  1. Open the Applications folder.
  2. The first time only: right-click (or Control-click) Conceptor, then click Open.
  1. A box says macOS cannot verify the developer. Click Open.
  2. From then on, open Conceptor normally (Dock, Launchpad or Applications).
  1. The first time you record, macOS asks about the microphone. Click OK.

Updating later: download the new .dmg, drag Conceptor onto Applications, and click Replace. Songs are kept.

Mac and PC in the browser

Already installed from Chrome or Edge: open it while online. It updates itself. If it still looks like 0.4 (yellow buttons, no honeycomb), close the window and open it again.

New:

  1. Open Chrome or Edge (Safari also works on a Mac).
  2. Go to ftumch78.github.io/conceptor-web.
  3. Click Open Conceptor.
  4. Click the install icon at the right end of the address bar, then Install.
  5. Click Start, then allow the microphone.

Library in OneDrive or Google Drive (computer)

Needs Chrome or Edge on a computer, and the OneDrive or Google Drive app on that computer.

  1. In Conceptor, open the Menu, then Library.
  2. Press Library Location.
  3. Choose Also in a synced folder (OneDrive or Google Drive).
  4. Press Choose folder. Pick the OneDrive or Google Drive folder. Allow Conceptor to use it.
  5. Press Sync Library, then A synced folder, then Start sync (or Combine and sync if a Library is already there).

Conceptor makes a folder called "Conceptor Library". Each song is a folder inside it, with song.txt, the track WAV files and the exported mixes. Nothing is deleted when syncing. If the same song was changed in two places, both copies are kept.

Library in a synced folder (Android)

  1. Open the Menu, then Library.
  2. Press Library Location, then Also in a folder kept in sync.
  3. Press Choose folder and pick the folder. Allow access.
  4. Press Sync Library, then the folder option, then Start sync.

The folder must be one the phone can write to, such as a OneDrive folder or a folder that a sync app keeps in step with the cloud. The Google Drive app does not offer folders this way.
